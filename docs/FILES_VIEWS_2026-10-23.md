# 全局与邮箱文件视图（2026-10-23）

基于已发布的附件版本 `40a95a4` 开发。本次功能已完成本地验证，并于 2026-10-23 23:54（北京时间）发布到正式站点。

后续性能改造见 [统一文件索引（2026-10-24）](./FILE_INDEX_2026-10-24.md)。以下保留本次发布时的实现与验收记录。

## 功能

- 邮箱目录新增「全局文件」，路径 `/files`。默认汇总全部邮箱，可精确选择某个邮箱。
- 每个邮箱侧栏新增「文件」，路径 `/mailbox/:mailboxId/files`，只列出当前邮箱的附件，并提供进入全局视图的链接。
- 两个视图共用组件，支持全部 / 收到 / 发出筛选、文件名 / 主题 / 收发地址搜索、每页 25 个文件及刷新。条件保存在 URL 中。
- 列表显示文件名、大小、邮件时间、收发对象、邮件主题；全局列表额外标明所属邮箱。
- 点击文件名可预览图片、PDF、文本。PDF 支持翻页并适配窄屏，文本以纯文字显示，最多预览前 200 KB。其他格式、超过 25 MiB 的文件和受密码保护的 PDF 提供原文件下载。
- 点击邮件主题回到对应邮件；全局列表会切换到所属邮箱并打开该邮件。下载继续通过既有的邮箱 / 邮件 / 附件归属校验。
- 默认排除草稿、垃圾箱和正文内嵌图片；「包含正文图片」可显示内嵌附件。
- 工作区不再挂载 Agent / MCP 侧栏，顶部机器人入口也已隐藏；不改变后端 Agent、MCP 或 Access 配置。

## 实现

- 新增 `GET /api/v1/files` 和 `GET /api/v1/mailboxes/:mailboxId/files`。
- 参数为 `page`、`limit`、`q`、`direction`、`includeInline`；全局接口额外支持 `mailbox`。输入在服务端校验，页码超过末页时返回最后一页。
- 单邮箱查询直接连接附件与邮件元数据，不读取邮件正文和 R2 文件内容；总数和分页使用相同筛选。
- 全局接口遍历完整邮箱目录，最多并发查询 6 个邮箱，再按时间、邮箱和附件标识合并。每个邮箱按需读取后续页，不截断在目录首批 1,000 个邮箱。任一邮箱读取失败时返回 503，不把部分列表当作全量结果。
- 本次不增加全局文件索引；首次全局查询仍需要访问每个邮箱，较深的分页需要读取前序元数据。单邮箱筛选可直接访问对应邮箱。
- 增量迁移 `10_preserve_email_direction` 保存邮件的原始收发方向；新收件、发件在归档或移动文件夹后仍保持分类，来自自己邮箱的收件也能正确识别。迁移为历史收件箱 / 垃圾邮件 / 已发送记录补齐方向，不改正文或附件。更早已移至归档及自定义文件夹的记录缺少原始方向，使用精确发件地址（兼容 `Name <address>`）回退判断。
- PDF 渲染器固定为 `pdfjs-dist@6.4.299`，只在预览时加载。`predev` / `prebuild` 准备同站点字体、字符映射和解码资源，不上传附件到第三方预览服务；生成的资源不纳入 Git。
