## API 与存储

`GET /api/v1/mailboxes?page=1&limit=25&q=address&domain=dev.jdtogo.ai`

响应包含 `mailboxes`、`totalCount`、`page`、`limit`、`totalPages`。`limit` 范围 1–100，网页提供 25/50/100；无结果时 `page=1`、`totalPages=1`。过大的合法页码回到最后一页。非法页码、每页数量和过长搜索条件返回 400；目录存储读取失败返回 503，网页不会把失败当成无结果。

服务端通过 R2 cursor 读完 `mailboxes/` 的全部索引，再筛选、排序和分页；不再受首批 1000 个对象限制。目录查询只读取对象列表，不读取邮箱设置、邮件正文或附件，也不调用邮箱 Durable Object。为了提供准确总数，每次未缓存的查询仍需遍历目录索引，未引入额外数据库或索引迁移。

不带目录参数的旧接口继续返回数组，供现有调用方和配置地址的自动创建流程使用。存在 `EMAIL_ADDRESSES` 时，网页目录仍仅展示配置中的地址。
